# Stitch Design Outputs

> 기준일: 2026-06-21  
> 목적: Google Stitch에서 생성한 Flutter v1 화면 이미지와 HTML 참고 코드를 화면명 기준으로 보관해요.

## Naming Rule

- 화면 폴더명은 `docs/mobile-flow-spec.md`의 v1 화면 흐름과 실제 Stitch 산출물 화면명을 기준으로 사용해요.
- 각 화면 폴더는 아래 두 파일을 포함해요.
  - `{screen_name}.png`: 화면 이미지
  - `{screen_name}.html`: Stitch가 제공한 HTML 참고 코드
- HTML은 Flutter 구현 시 시각 구조, spacing, radius, typography hierarchy를 참고하기 위한 자료예요.
- HTML 구조를 Flutter 위젯 구조로 그대로 변환하지는 않아요.
