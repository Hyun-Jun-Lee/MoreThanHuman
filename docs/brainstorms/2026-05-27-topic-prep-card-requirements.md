# Topic Prep Card Requirements

## Summary

대화 전 주제 준비 카드는 사용자가 입력한 관심 주제를 검색 기반으로 짧게 요약하고, 사용자가 대화 방향을 고른 뒤 AI 첫 질문 3개 중 하나에 답하면서 대화를 시작하게 하는 준비 화면이다. 첫 버전은 학습 자료가 아니라 말문을 여는 장치에 집중한다.

---

## Problem Frame

Convia의 핵심 가치는 정해진 커리큘럼 대신 사용자가 원하는 최신 관심사로 영어 회화를 시작하게 하는 것이다. 다만 사용자가 주제만 입력한 상태에서는 무엇을 어떻게 말해야 할지 막힐 수 있고, 검색 결과가 대화로 연결되지 않으면 일반 검색 요약이나 챗봇과 차별점이 약해진다.

주제 준비 카드는 검색 컨텍스트를 사용자의 첫 발화로 이어주는 다리 역할을 한다. 사용자가 대화 방향을 먼저 정하고 AI의 첫 질문을 골라 답하게 하면, 대화 시작 부담을 줄이면서도 사용자가 주도권을 가진다는 제품 전략을 살릴 수 있다.

---

## Key Decisions

- **대화 시작에 집중한다.** v1은 단어, 표현, 문법 포인트를 보여주는 학습 카드가 아니라 사용자가 바로 대화를 시작하게 만드는 준비 카드로 제한한다.
- **대화 방향은 4개로 제공한다.** `캐주얼 대화`, `찬반토론`, `인터뷰/질문답변`, `설명 연습`을 제공해 선택권을 주되, 선택 피로가 커지지 않게 한다.
- **첫 발화는 AI 질문 선택으로 시작한다.** 사용자가 직접 첫 문장을 만들어야 하는 부담을 줄이기 위해, AI가 제안한 첫 질문 3개 중 하나를 골라 답하면서 대화를 시작한다.
- **검색 품질이 낮으면 재입력을 유도한다.** 부정확하거나 빈약한 컨텍스트로 카드를 만들기보다, 더 구체적인 주제를 입력하도록 안내한다.

---

## Requirements

**Topic preparation**

- R1. 사용자는 대화 시작 전 원하는 관심 주제를 입력할 수 있어야 한다.
- R2. 시스템은 입력된 주제를 바탕으로 검색 결과 기반의 짧은 주제 요약을 생성해야 한다.
- R3. 주제 요약은 사용자가 대화할 배경을 빠르게 이해할 수 있을 만큼 구체적이어야 하며, 장문의 기사 요약처럼 길어지면 안 된다.

**Conversation direction**

- R4. 사용자는 준비 카드에서 `캐주얼 대화`, `찬반토론`, `인터뷰/질문답변`, `설명 연습` 중 하나의 대화 방향을 선택할 수 있어야 한다.
- R5. 각 대화 방향은 사용자가 어떤 방식으로 말하게 될지 이해할 수 있는 짧은 설명을 가져야 한다.
- R6. 선택된 대화 방향은 이후 AI의 첫 질문과 대화 흐름에 반영되어야 한다.

**First-question start**

- R7. 시스템은 선택된 대화 방향에 맞는 AI 첫 질문 3개를 제안해야 한다.
- R8. 사용자는 제안된 첫 질문 중 하나를 선택하고, 그 질문에 답하면서 대화를 시작할 수 있어야 한다.
- R9. 첫 질문은 검색 요약의 구체적인 내용과 연결되어야 하며, 너무 일반적인 영어 회화 질문으로 흐르면 안 된다.

**Search quality gate**

- R10. 시스템은 카드 생성 전 검색 결과의 품질을 판단해야 한다.
- R11. 검색 품질 판단은 출처 수, 주제 관련성, 최신성, 구체성을 기준으로 삼아야 한다.
- R12. 검색 품질이 낮으면 카드를 생성하지 않고, 사용자가 더 구체적인 주제를 다시 입력하도록 안내해야 한다.
- R13. 재입력 안내는 사용자가 어떻게 고치면 좋은지 예시를 포함해야 한다.

---

## Key Flows

- F1. Topic prep success
  - **Trigger:** 사용자가 관심 주제를 입력한다.
  - **Steps:** 시스템이 검색 결과를 수집하고 품질을 판단한다. 품질이 충분하면 짧은 요약과 4개 대화 방향을 보여준다. 사용자가 대화 방향을 선택하면 AI 첫 질문 3개를 보여준다. 사용자가 질문 하나를 선택하고 답변하면서 대화를 시작한다.
  - **Covered by:** R1, R2, R4, R6, R7, R8

- F2. Low-quality search result
  - **Trigger:** 사용자가 입력한 주제의 검색 결과가 부족하거나 대화 준비에 충분하지 않다.
  - **Steps:** 시스템은 준비 카드를 만들지 않고, 더 구체적인 주제를 입력하라는 안내와 예시를 보여준다. 사용자는 주제를 수정해 다시 시도할 수 있다.
  - **Covered by:** R10, R11, R12, R13

## Acceptance Examples

- AE1. **Covers R4, R7, R8.**
  - **Given:** 사용자가 “최근 Dodgers 경기 결과”를 주제로 입력했고 검색 품질이 충분하다.
  - **When:** 사용자가 `찬반토론` 방향을 선택한다.
  - **Then:** 시스템은 경기 내용과 연결된 찬반형 첫 질문 3개를 보여주고, 사용자는 질문 하나를 골라 답변하며 대화를 시작한다.

- AE2. **Covers R9.**
  - **Given:** 준비 카드가 “최근 야구 경기” 검색 요약을 만들었다.
  - **When:** 시스템이 첫 질문을 제안한다.
  - **Then:** 질문은 “Do you like baseball?”처럼 일반적인 질문만으로 구성되지 않고, 검색 요약의 사건, 선수, 결과, 쟁점 중 하나 이상과 연결된다.

- AE3. **Covers R11, R12, R13.**
  - **Given:** 사용자가 “요즘 이슈”처럼 너무 넓은 주제를 입력했다.
  - **When:** 검색 결과가 구체적인 대화 준비에 충분하지 않다고 판단된다.
  - **Then:** 시스템은 카드를 생성하지 않고 “최근 야구 경기”보다 “2026년 5월 Dodgers 경기 결과”처럼 더 구체적인 예시를 포함해 재입력을 안내한다.

---

## Success Criteria

- 사용자는 준비 카드에서 대화 방향을 선택하고 첫 질문을 골라 대화를 시작할 수 있다.
- 준비 카드로 시작한 대화는 전략 지표인 주제 기반 대화 시작률과 대화 지속 턴 수를 개선하는 방향으로 측정 가능해야 한다.
- 검색 품질이 낮은 경우에도 부정확한 대화 컨텍스트를 만들지 않고 재입력 흐름으로 회복할 수 있다.

---

## Scope Boundaries

- 핵심 단어, 표현, 문법 포인트 제공은 v1 범위에서 제외한다.
- 검색 없는 fallback 카드 생성은 v1 범위에서 제외한다.
- 관심사 저장/재사용은 별도 후속 기획으로 둔다.
- 대화 후 리캡은 별도 후속 기획으로 둔다.

---

## Dependencies / Assumptions

- 사용자는 대화 시작 전 관심 주제를 입력할 의지가 있다.
- 검색 결과는 대화 준비에 충분한 최신성과 구체성을 제공할 수 있다.
- 기존 검색 요약과 대화 시작 흐름은 주제 준비 카드가 사용할 수 있는 기반으로 확장 가능하다.
