# tomatalk 공개 웹사이트

> 결정: 2026-11-03 · 공개 주소: `https://curitalk.app`

## 목적과 범위

- Vercel에서 정적 사이트로 `/`, `/support`, `/privacy`를 제공해요. API는 기존 `api.curitalk.app`을 유지해요.
- 모바일 앱의 [디자인 시스템](design/DESIGN_SYSTEM.md)을 사용해요. 흑백 타이포그래피, Freesentation, 파스텔 콘텐츠 면, 큰 둥근 모서리를 기준으로 해요.
- 공통 헤더와 하단 영역은 제공된 TOMATALK 가로형 로고를 사용해요. 원본의 검은 사각형과 넓은 여백을 제거한 투명 웹용 파일을 `website/assets/wordmark.png`에 보관해요. 앱 아이콘은 파비콘과 히어로에 계속 사용해요.
- 기능 카드의 높이는 제목과 설명을 읽을 만큼만 확보해 카드 내부의 불필요한 빈 공간을 줄여요.
- 한국어와 영어를 별도 URL로 제공해요. 기본 경로는 한국어이며 `/en`, `/en/support`, `/en/privacy`는 영어예요.
- 앱 미리보기 제목은 한국어에서 “tomatalk에서는 이렇게 대화해요.”로 안내하고 영어에서도 같은 의미를 전달해요.
- 첫 출시 전 다운로드 버튼은 목적지가 생기기 전까지 비활성화하고 출시 예정 상태를 표시해요. 실제 App Store 주소가 생기면 버튼을 연결해요.
- 이용약관은 Apple 표준 EULA를 사용하고 자체 `/terms`는 만들지 않아요.

## 내용 출처

- 기능 문구는 현재 Flutter 앱과 `docs/DSL.md`의 구현 범위만 설명해요. 구독·비즈니스 대화 모드는 출시 전 검증 또는 미구현 상태이므로 랜딩에서 홍보하지 않아요.
- 미리보기에는 출시 빌드의 실제 캡처를 사용해요. `docs/design/stitch_design/`의 PNG는 디자인 참고 자료이며 실제 앱 캡처로 표시하지 않아요.
- 스크린샷은 언어별로 `website/assets/screenshots/ko/screen-1.png`부터 `screen-3.png`, `website/assets/screenshots/en/screen-1.png`부터 `screen-3.png`에 넣어요. 같은 언어의 3장이 모두 있을 때만 해당 언어 페이지에 표시해요. 각 이미지와 캡션의 장면을 대조해요.
- 지원 연락처는 `tomatalk.support@gmail.com`, 운영 주체는 엑셈플러예요.
- 개인정보처리방침은 Supabase Pro 백업을 최대 7일 보관하는 운영 결정을 반영해요. 실제 자동 백업 설정과 삭제 후 복원 시 재삭제 절차를 확인한 뒤 공개해요. 생성 음성 캐시 파일은 복구 대상이 아니며 기본 만료는 30일이에요.

## 배포 전 확인

1. 실제 한국어·영어 앱 화면 캡처를 추가하고 화면별 설명 문구가 일치하는지 확인해요. 현재 전달된 시뮬레이터 임시 파일은 접근할 수 없어 이미지가 포함되지 않았어요.
2. Vercel의 `curitalk.app` HTTPS 및 공개 경로를 로그인 없이 확인해요.
3. Supabase Pro의 자동 백업과 7일 보관 상태를 확인하고, 복원 시 삭제 요청을 다시 적용할 절차를 마련해요. 이 확인 전에는 `/privacy`를 App Store에 제출하지 않아요.
4. 앱의 개인정보처리방침 접근 경로와 외부 AI 처리 안내를 확인해요.
5. App Store 다운로드 URL이 공개된 뒤 CTA를 연결해요.
