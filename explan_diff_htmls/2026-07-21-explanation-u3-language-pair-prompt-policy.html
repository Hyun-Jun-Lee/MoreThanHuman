U3 · Prompt Policy

LLM prompt에 언어별 학습 기준을 심은 작업

U3는 “Korean으로 말하라”에서 한 걸음 더 나아가 “Korean을 배울 때 무엇을 봐야 하는가”를 prompt contract로 만든 작업이에요. conversation, roleplay, grammar, Topic Prep이 같은 기준을 공유하게 됩니다.

Background

언어쌍이 일급 도메인이 되면 backend prompt도 단순히 출력 언어만 바꾸면 부족합니다. 같은 “문법 피드백”이라도 한국어와 영어에서 봐야 하는 오류의 종류가 다르기 때문이에요.

U3 이전에도 prompt는 `LearningLanguageContext`를 받았습니다. 하지만 conversation prompt는 일반적인 대화 규칙에 가까웠고, grammar prompt는 Korean 분기만 구체적이었으며, Topic Prep은 언어 구분은 하되 학습 포인트는 얇았습니다. 이런 상태에서는 화면은 한국어 학습처럼 보이는데 feedback은 영어식 기준에 가까워지는 drift가 생길 수 있어요.

정책의 불변식 target language는 연습과 교정 기준을 정합니다. feedback language는 설명 언어를 정합니다. Provider, model, API schema는 U3에서 바뀌지 않습니다.

Conversation

free chat과 roleplay 모두 같은 practice priorities를 받습니다.

Grammar

언어별 correction priorities를 쓰되 JSON schema는 유지합니다.

Topic Prep

요약, 질문, 품질 판정이 target-language practice에 맞게 유도됩니다.

Intuition

좋은 prompt 정책은 여러 prompt에 같은 문장을 복붙하는 것이 아니라, 같은 사고방식을 여러 prompt가 공유하게 만드는 것입니다. 그래서 U3는 작은 shared module을 만들고, 각 domain prompt가 필요한 형태로 포맷해서 가져가게 했습니다.

이전

prompt마다 언어별 기준이 흩어져 있었고, generic English-shaped rule이 다른 target에도 섞일 위험이 있었습니다.

이후

공통 policy helper가 target-language 기준을 만들고, 각 prompt는 그 기준을 자기 역할에 맞게 삽입합니다.

Code

1. Prompt policy를 shared module로 분리한다

`backend/shared/language_prompt_policy.py`는 enum/context primitive와 분리된 prompt-oriented helper입니다. 언어 검증이 아니라 LLM에게 줄 학습 기준 문장을 담습니다.

@dataclass(frozen=True)
class TargetLanguagePromptPolicy:
    practice_priorities: tuple[str, ...]
    correction_priorities: tuple[str, ...]
    topic_prep_priorities: tuple[str, ...]

def target_language_prompt_policy(
    language: LanguageCode | str,
) -> TargetLanguagePromptPolicy:
    code = language if isinstance(language, LanguageCode) else LanguageCode(language)
    if code == LanguageCode.KOREAN:
        return KOREAN_PROMPT_POLICY
    if code == LanguageCode.ENGLISH:
        return ENGLISH_PROMPT_POLICY
    return GENERIC_PROMPT_POLICY

2. Conversation prompt에 practice priorities를 넣는다

free chat과 roleplay는 모두 “짧게, 자연스럽게, target language로”라는 규칙을 유지하면서 그 앞에 target-specific learning priorities를 추가합니다.

practice_priorities = format_practice_priorities(
    language_context.target_language
)

base_prompt = f"""You are a friendly and helpful {target_name} conversation learning assistant.

## Learner Language Context:
- Native language: {native_name}
- Practice target language: {target_name}
- Feedback/explanation language: {feedback_name}

## Target Language Practice Priorities:
{practice_priorities}
"""

3. Grammar prompt는 Korean과 English를 명시적으로 분기한다

Korean branch는 영어식 subject-verb agreement를 적용하지 말라는 방어선을 유지합니다. English branch는 generic prompt가 아니라 영어의 핵심 오류 범주를 직접 봅니다.

if language_context.target_language == LanguageCode.KOREAN:
    return f"""Analyze the following Korean response...
2. Check Korean-specific issues:
{correction_priorities}
3. Do not apply English grammar rules such as subject-verb agreement to Korean.
4. Explain issues in {feedback_name}.
"""

if language_context.target_language == LanguageCode.ENGLISH:
    return f"""Analyze the following English response for grammar errors.
MUST CHECK FOR THESE ERRORS:
{correction_priorities}
"""

4. Topic Prep과 search prompt에도 practice summary를 넣는다

검색 품질 판정과 요약은 단지 좋은 검색 결과를 찾는 일이 아닙니다. 대화 연습으로 쓸 수 있는 결과를 고르는 일이므로 target-language practice priority가 품질 판단에도 들어갑니다.

practice_summary = practice_priority_summary(
    language_context.target_language
)

content=(
    f"You are the primary source quality judge for a {target_name} conversation app. "
    f"Judge usefulness for target-language practice priorities: {practice_summary}. "
)
