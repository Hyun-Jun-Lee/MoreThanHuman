Background

언어 학습 앱에서 “무슨 상황을 연습할 것인가”는 단순한 copy가 아닙니다. 그것은 학습자가 어떤 언어적 문제를 만나게 될지를 결정하는 커리큘럼의 작은 입구예요.

기존 roleplay preset은 영어회화 앱에서 흔히 볼 수 있는 cafe, hotel, immigration, interview 중심이었습니다. 영어 target에는 여전히 좋은 출발점이지만, 한국어 target에서는 존댓말, 조사, 어미, 자기소개, 서비스 상황처럼 한국어다운 과제가 더 앞에 나와야 합니다.

U2의 기준 콘텐츠 선택은 target language가 결정합니다. 반면 low-quality retry 안내의 문장 언어는 feedback language가 결정합니다.

Roleplay preset

모바일에서 target language별 상황 목록을 보여줍니다.

Role character

preset/custom 선택을 하나의 `role_character` 문자열로 합성합니다.

Topic Prep examples

재시도 예시는 읽기 언어와 연습 방향을 동시에 만족해야 합니다.

Intuition

같은 “카페 주문”도 언어마다 학습의 중심이 다릅니다. 영어에서는 주문 표현과 옵션 질문이 중요하고, 한국어에서는 “주시겠어요”, “으로 할게요”, “괜찮습니다” 같은 어미와 공손함의 선택이 더 두드러질 수 있어요.

이전

하나의 preset 목록이 모든 학습자에게 보이고, backend prompt에는 `English Teacher` 같은 고정 영어 학습 예시가 남아 있었습니다.

이후

Korean target은 한국어다운 상황을 우선하고, English target은 기존 일상/여행/업무 영어 흐름을 유지합니다.

Code

1. 모바일 preset을 target language로 라우팅한다

`roleplayPresetScenarios` 하나를 모든 사용자에게 쓰는 대신, Korean target용 목록과 English target용 목록을 나누고 accessor로 감쌌습니다.

List<RoleplayScenario> roleplayPresetScenariosFor(
  LearningLanguageCode targetLanguage,
) {
  return switch (targetLanguage) {
    LearningLanguageCode.ko => koRoleplayScenarios,
    LearningLanguageCode.en => enRoleplayScenarios,
    LearningLanguageCode.zh => enRoleplayScenarios,
  };
}

2. Roleplay Setup 화면은 auth profile의 target을 본다

새 API를 만들지 않고, 이미 hydration된 `authControllerProvider`에서 target language만 select합니다. UI state는 그대로 두고 콘텐츠 목록만 바뀌는 구조예요.

final roleplayTargetLanguageProvider = Provider<LearningLanguageCode>((Ref ref) {
  return ref.watch(
    authControllerProvider.select(
      (AsyncValue<AuthSession> auth) =>
          auth.value?.user?.language.targetLanguage ??
          LearningLanguageContext.defaultContext.targetLanguage,
    ),
  );
});

3. Custom roleplay는 영어 예시에 묶이지 않는다

custom prompt의 예시는 cafe barista에 고정되어 있었지만, 이제 “사용자가 자신의 역할을 쓰면 반대 역할을 맡는다”는 규칙이 더 잘 드러납니다.

return 'a realistic counterpart in a learner-defined roleplay where the learner described their situation or role as "$normalizedInput"; '
    'if the learner describes their own role, play the opposite role in that situation; '
    'for example, if the learner is a hotel guest asking for help, play the front desk staff member';

4. Backend roleplay examples도 target-aware가 된다

모바일에서 Korean preset을 보여줘도 backend prompt가 영어 교사 예시를 들면 모델 행동은 다시 흔들릴 수 있어요. 그래서 scenario examples를 target language helper로 분리했습니다.

def _roleplay_scenario_examples(self, language_context: LearningLanguageContext) -> str:
    if language_context.target_language == LanguageCode.KOREAN:
        return (
            """        - Korean Cafe Staff: Taking polite orders...
        - Front Desk Staff: Helping with check-in...
        - New Colleague: Exchanging greetings...
        - Friend: Having casual conversation..."""
        )
    return (
        """        - Cafe Barista: Greeting customers...
        - Interviewer: Welcoming candidates...
        - Hotel Front Desk: Check-in procedures...
        - Meeting Participant: Making small talk..."""
    )

5. Topic Prep 재시도 예시는 두 축을 동시에 본다

예시 주제는 feedback language로 읽혀야 하지만, Korean target이면 한국어 연습에 좋은 상황으로 기울어야 합니다.

if language_context.target_language == LanguageCode.KOREAN:
    return self._build_korean_practice_example_topics(
        trimmed_topic,
        year,
        month,
        language_context=language_context,
    )
