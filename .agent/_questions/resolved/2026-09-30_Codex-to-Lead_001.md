# 무료 대화 제한과 추가 대화 잠금 정책

- 작성: 2026-09-30, Codex → Lead
- 우선순위: 해결됨 (2026-10-01)
- 관련 계획: [대화 권한 계획](../../../docs/plans/archive/2026-09-30-001-feat-conversation-access-plan.md)

1. 무료 플랜은 대화 동시 보유 1개예요. 삭제하면 재생성할 수 있어요.
2. 자물쇠는 아직 만들지 않은 추가 대화 자리에 붙여요. 기존 대화는 잠그지 않아요.
3. 기존 무료 계정은 정책 활성화 당시 보유 개수까지 삭제 후 재생성할 수 있어요.
4. 서버 제한과 잠금 UI를 함께 구현하지만 결제 기능이 준비될 때까지 비활성화해요.
5. 단품 구매는 동시 보유 한도를 1개 늘리는 영구 이용권이에요.
6. 무료 Topic Prep 횟수 제한은 없고, 무료 플랜의 각 대화에 15 user turns를 적용해요. 단품으로 추가한 대화도 포함해요.
7. 이미 15턴을 넘긴 무료 대화는 정책 활성화 후 열람은 가능하지만 추가 발화를 즉시 제한해요.
