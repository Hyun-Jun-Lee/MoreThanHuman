# tomatalk 마케팅 전략 제안

> 작성: 2026-09-15 · 버전: 0.1 · 상태: 검증 전 제안
> 범위: 한국어·영어 학습자 초기 고객 확보와 반복 사용 검증
> 가정: 출시 전 또는 초기 베타, 소규모 팀, 월 현금 예산 100만 원 이내예요. 출시 상태·기존 고객·가격·실제 예산은 확인되지 않았어요. 아래 숫자는 시장 평균이나 성과 예측이 아니라 실험 설계용 기준이에요.

## 1. 전략 요약

**“관심 있는 주제로, 실제로 하고 싶은 말을 연습하는 회화 앱”으로 소개해요.** 한국어 학습자와 영어 학습자는 하나의 브랜드 아래 별도 메시지·소개 페이지·성과 집계로 운영해요. 첫 4주에는 각 20명의 체험자를 확보하는 것을 모집 목표로 삼고, 재사용 경험이 좋은 고객군과 채널에 다음 자원을 집중해요.

초기 확보 경로는 학습자 커뮤니티와 소규모 언어 교육 크리에이터, 홍보 소재는 실제 앱 대화를 담은 짧은 영상이에요. 관심을 실제 연습으로 연결하는 “7일 말하기 미션”을 운영해요. 유료 광고 확대는 첫 대화와 재방문을 확인한 뒤 결정해요.

## 2. 현재 서비스와 홍보 가능한 약속

[README](../../README.md)의 제품명 tomatalk을 사용해요. [API 명세](../../docs/DSL.md), [아키텍처](../architecture.md), [모바일 언어 모델](../../mobile/lib/features/language/domain/learning_language.dart)을 함께 확인했어요.

| 확인한 기능 | 사용자가 얻는 경험 | 홍보 시 보여줄 장면 |
|---|---|---|
| 관심 주제 검색·대화 준비 | 무슨 이야기를 할지 정하고 첫 질문을 받아요 | 좋아하는 주제 입력 → 준비 카드 → 첫 답변 |
| 상황별·직접 입력 롤플레이 | 실제로 필요한 상황을 미리 연습해요 | 카페 주문, 취향 설명, 여행 중 부탁하기 |
| 텍스트·녹음 입력과 AI 음성 응답 | 쓰거나 말하면서 대화를 이어가요 | 실제 음성 입력과 응답 재생 |
| 문법 피드백과 설명 | 자신이 말한 문장을 다시 살펴봐요 | 원문·교정문·설명 표시 |
| 언어 스낵 | 짧은 표현 차이와 언어 지식을 접해요 | 표현 카드 → 그 표현을 활용할 연습 제안 |

모바일에서 선택 가능한 학습 흐름은 한국어 설명으로 영어 학습, 영어 설명으로 한국어 학습이에요. 따라서 해외 한국어 학습자의 초기 조건은 영어 설명을 이해할 수 있는 성인이에요. 중국어 지원은 초기 홍보 범위에 포함하지 않아요.

위 내용은 저장소의 구현·문서 근거이며 앱스토어 출시나 운영 품질을 확인한 결과는 아니에요. 정밀 발음 채점, 완전 실시간 통화, 시험 점수 향상, 체계적인 입문 커리큘럼, 자동 복습, 무제한 무료 사용을 현재 제품의 약속으로 쓰지 않아요. 발음 채점과 녹음의 텍스트 변환은 다른 기능이에요.

## 3. 시장 근거와 포지셔닝

- Duolingo의 2025 보고서에서 영어는 플랫폼 내 인기 학습 언어 1위, 한국어는 6위예요. 집계 기간은 2024-10-01부터 2025-09-30이며, 전체 시장 규모나 유료 수요를 뜻하지 않아요. [Duolingo 보고서](https://blog.duolingo.com/2025-duolingo-language-report/)
- 세종학당재단은 2025년 수강생 239,020명을 발표했고, 한국어 관심이 유학·진로·방한 경험으로 이어지는 흐름을 설명해요. 이를 바탕으로 한국어 캠페인은 문화적 관심과 실제 생활 목적을 함께 다루는 가설을 세워요. 재단 수강생 자료를 영어권 고객의 구매 의향으로 일반화하지 않아요. [재단 발표, 2026-04-16](https://ksif.or.kr/cop/bbs/selectBoardArticle.do?bbsId=BBSMSTR_000000000141&nttId=9220000007869&pageIndex=1)
- Speak도 관심 주제로 맞춤 말하기 수업을 만들고 실생활 회화를 연습하는 기능을 설명해요. TEUIDA도 실제 상황과 말하기, 발음 피드백을 전면에 내세워요. 따라서 “AI”, “개인화”, “실생활”만으로 독점적인 차별점이 생기지는 않아요. [Speak 공식 안내](https://help.speak.com/en/articles/11396739-what-is-speak-tutor), [TEUIDA 공식 소개](https://www.teuida.net/en)

**경쟁 가설:** tomatalk의 검색 기반 대화 준비부터 첫 답변, 설명 피드백까지 이어지는 흐름이 특정 학습자에게 시작 부담을 줄여 줄 수 있어요. 이것은 검증할 가치 제안이며, 경쟁 제품보다 우수하다는 확인된 결과가 아니에요.

기존 교재나 강의를 쓰는 사람에게는 “배운 것을 실제로 말해 보는 연습 도구”로 소개해요. 기존 학습 습관에 추가할 이유를 설명하기 쉬워요. 범용 AI를 이미 활용하는 체험자에게는 현재 방식과 tomatalk으로 같은 주제를 연습하게 하고, 시작에 걸리는 시간·도움이 된 설명·다시 쓰고 싶은 이유를 비교해요.

## 4. 고객군별 전략

| 항목 | 한국어 학습자 | 영어 학습자 |
|---|---|---|
| 첫 고객 가설 | 영어 설명을 이해하고 한글·기초 문장을 알며, 한국 방문·유학·생활을 준비하는 성인 | 기본 문장은 알지만 대화를 이어가기 어려운 한국인 성인 |
| 당면 문제 | 주문·부탁·자기소개를 배웠지만 상대방의 추가 질문에 답하기 어려워요 | 관심사에 관해서도 첫 문장 뒤에 할 말이 막혀요 |
| 첫 캠페인 | 한국 방문 전 7일 말하기 연습 | 좋아하는 주제로 하루 5분 말하기 |
| 메시지 | “Practice the Korean conversations you’ll actually have.” | “좋아하는 이야기를 영어로 이어가 보세요.” |
| 시연 | 주문 → 옵션 질문 → 부탁을 덧붙이는 대화 | 영화·여행·취미 입력 → 질문 → 내 의견 → 교정 설명 |
| 핵심 유입 경로 | 영어로 한국어를 가르치는 소규모 크리에이터·학습 모임 | 영어 공부 기록 크리에이터·영어 스터디 커뮤니티 |
| 반복 사용 이유 | 다음 생활 상황과 자신의 관심사를 연습해요 | 관심 주제를 바꾸고 이전에 막힌 문장을 다시 써요 |

한국어는 영어로 운영되는 학습자 커뮤니티 한두 곳에서 출발해요. 영어권 전체에 동시에 광고하지 않아요. 체험자 소재지·사용 언어·참여 가능한 시간을 기록해 이후 국가 확대를 판단해요. 한국어 교사나 모임에 접근할 수 있는 기존 인맥이 있다면 그 경로를 우선해요.

두 언어의 첫 20명은 방향을 탐색하는 표본이에요. 연령·국가별 시장 우열이나 광고 효율을 확정하는 표본은 아니에요. 모집이 어렵다면 이유와 투입 시간을 기록하고, 더 작은 그룹으로 인터뷰를 먼저 진행해요.

## 5. 채널 우선순위

### 1순위: 학습 모임과 소규모 교육 크리에이터

팔로워 수보다 실제 학습 질문이 달리는지, 청중의 설명 언어가 맞는지, 진행자가 직접 앱을 써 볼 수 있는지를 기준으로 선정해요. 한국어 교사, 한국 생활 준비 콘텐츠 제작자, 영어 공부 기록 계정이 후보예요. 특정 단체의 제휴나 홍보 허용 여부는 확인되지 않았어요.

첫 협업 제안은 “7일간 직접 써 보고, 막힌 문장 하나와 실제 피드백 장면을 보여주는 체험”이에요. 대본 낭독형 추천보다 사용 과정을 남기도록 해요. 보상은 제작·참여에 지급하고 긍정적 리뷰나 앱스토어 별점과 연결하지 않아요. 이번 문서는 제안만 작성하며 외부 연락·게시·결제를 실행하지 않아요.

커뮤니티에는 도움이 되는 미션 예시와 사용 장면을 먼저 제공하고, 운영 규칙상 모집이 가능한 공간에서 체험자를 받아요. 관심 없는 회원에게 일괄 메시지를 보내는 방식은 사용하지 않아요.

### 2순위: 실제 대화를 담은 짧은 영상

처음에는 Instagram Reels를 공통 실험 채널로 정하고, 한국어 설명과 영어 설명 콘텐츠의 계정·프로필 링크를 구분해요. 주당 원본 4개, 학습 언어별 2개를 제작하는 것을 운영 상한으로 잡아요. 제작 여력이 생기면 같은 소재를 Shorts나 TikTok에 맞게 편집해요. 이 채널 선택은 성과가 확인된 사실이 아니라 테스트할 가설이에요.

영상 구조: **막히는 상황 제시 → 실제 앱 대화 → 문장 피드백 → 같은 상황 연습하기**. 언어 스낵은 표현 차이를 설명하는 콘텐츠 원천으로 활용하되, 시청 뒤 말하기로 이어지는 미션을 붙여요. 스낵에서 대화로 자동 이동하는 앱 기능이 있다는 뜻은 아니에요.

| 캠페인 소재 | 첫 문장 예시 | 제품 시연 | 행동 유도 |
|---|---|---|---|
| 한국어 카페 대화 | “You ordered in Korean. What if they ask one more question?” | 주문 뒤 추가 질문에 대답하기 | “Try this café conversation.” |
| 한국어 취향 설명 | “Can you explain why you love that K-drama—in Korean?” | 좋아하는 작품과 이유로 대화 시작 | “Practice talking about your favorite show.” |
| 영어 취미 대화 | “취미가 뭐냐는 질문, 한 문장 뒤에 막히나요?” | 취미를 고르고 두 번째 답변까지 이어가기 | “내 취미로 5분 연습하기” |
| 영어 표현 피드백 | “I enjoyed it. 다음에는 뭐라고 말할까요?” | 자신의 이유를 덧붙이고 설명 확인 | “내 문장으로 대화 이어가기” |

영상의 원문·교정문은 실제 제품 결과를 사용하고, 교육 설명은 사람이 검토해요. 홍보용 데모는 데모로 표시해요. 대기 구간을 편집하면 편집 사실을 표시해 실제 응답 속도를 오해시키지 않아요. “하루 5분”과 “7일”은 참여 분량이며 학습 성과를 보장하는 기간이 아니에요.

### 3순위: 목적이 구체적인 검색 콘텐츠와 스토어 소개

“AI 영어 앱”처럼 넓은 주제보다 “영어로 취미 설명하기”, “한국 카페에서 주문 후 질문에 답하기”처럼 실제 연습 상황별 페이지를 만들어요. 초반에는 언어별 핵심 페이지 1개씩으로 시작해요. 검색 유입 규모나 키워드 난이도는 이번 조사에서 측정하지 않았으므로 트래픽을 예측하지 않아요.

출시 뒤에는 앱스토어 스크린샷도 학습 대상별 메시지를 맞춰요. Apple은 다른 스크린샷·소개 문구와 고유 링크를 갖는 Custom Product Pages를 지원하며 노출 전 심사가 필요해요. 앱 출시 상태를 충족한 다음 적용할 수 있어요. [Apple 공식 안내](https://developer.apple.com/help/app-store-connect/create-custom-product-pages/configure-multiple-product-page-versions)

유료 광고는 전환을 확인한 메시지 하나, 고객군 하나, 채널 하나에 소액으로 집행하는 후속 실험이에요. 초기부터 광범위한 앱 설치 캠페인이나 여러 국가·채널을 동시에 열지 않아요.

## 6. 가입부터 재사용까지

**콘텐츠 → 언어별 소개 페이지 → 베타 참여 또는 설치 → 첫 대화 → 피드백 확인 → 다음 날 연습** 순서로 설계해요.

소개 페이지에는 대상 고객, 실제 시연 영상, 연습 상황 3개, 설명 언어, 현재 사용 조건, 행동 버튼 하나를 배치해요. 미출시 상태라면 “베타 참여 신청”, 배포가 가능하면 “연습 시작”을 사용해요. 신청자 수와 실제 사용자는 분리 집계해요.

영상에서 본 상황을 앱에서 찾도록 간단한 시작 안내를 제공해요. 특정 상황으로 바로 이동하는 링크, 가입 전 체험, 자동 미션·알림, 공유 카드, 추천 보상은 추가 제품 작업 후보예요. 초기 검증에서는 안내 페이지와 사용자가 선택한 연락 수단으로 수동 운영할 수 있어요. 현재 기능으로 구현돼 있다고 소개하지 않아요.

### 7일 말하기 미션 제안

| 일차 | 한국어 학습 | 영어 학습 |
|---|---|---|
| 1 | 자기소개와 한국 방문 목적 | 자기소개와 관심사 |
| 2 | 카페 주문과 추가 질문 | 좋아하는 음식과 이유 |
| 3 | 길을 묻고 다시 확인하기 | 최근 본 영화 설명 |
| 4 | 정중하게 부탁하기 | 여행 경험 설명 |
| 5 | 좋아하는 한국 콘텐츠 소개 | 관심 주제에 대한 의견 |
| 6 | 앞서 막힌 표현을 새 문장에 사용 | 앞서 막힌 표현을 새 문장에 사용 |
| 7 | 자신의 상황을 골라 도움 없이 연습 | 자신의 주제를 골라 도움 없이 연습 |

새 커리큘럼 기능을 개발하기보다 현재 롤플레이·주제 입력으로 수행 가능한 운영 미션으로 시작해요. 당일에 확인할 것은 “완벽한 답변”이 아니라 연습 완료와 다음에 말하고 싶은 내용이에요. 공개 후기·대화 캡처는 본인이 공개에 동의한 사례만 활용해요.

유료화는 별도 검증이에요. 반복 사용자에게 어떤 경험을 계속 쓰고 싶은지와 가격 수용 범위를 묻되, 설문 응답을 결제 전환으로 집계하지 않아요. 가격·체험 한도는 음성·LLM 비용과 실제 사용량을 확인한 뒤 결정해요. 결제·구독 구현 및 판매 조건은 이번 확인 범위에서 입증되지 않았어요.

## 7. 첫 8주 실행안

| 기간 | 작업 | 결과물·판단 |
|---|---|---|
| 1주 | 언어별 5명 인터뷰·첫 사용 관찰, 각 언어 실제 음성 대화·피드백 흐름 확인 | 반복되는 문제 3개, 이탈 구간, 언어별 소개 문구 |
| 2주 | 소개 페이지 2개, 시연 영상 총 4개, 모집 후보 채널 조사 | 메시지와 신청·시작 경로 준비 |
| 3·4주 | 각 언어 체험자 20명 모집 목표, 7일 미션을 시차를 두고 운영 | 참여자별 첫 대화·7일 재방문 기록 |
| 5·6주 | 반복 사용이 좋은 고객군·소재에 집중, 소규모 협업 1건부터 테스트 | 선택 고객군 70%, 다른 고객군 30%의 운영 시간 배분안 |
| 7·8주 | 조건을 충족하면 광고 소재 하나에 소액 집행, 후기·반복 사용 이유 정리 | 채널별 유지 사용자 확보 비용, 다음 달 집중 여부 |

같은 표본에서 타깃·메시지·플랫폼을 한꺼번에 바꾸지 않아요. 첫 모집 목표를 달성하지 못하면 일정에 맞춰 광고를 확대하지 않고, 모집 경로와 제안을 조정해요. 한국어와 영어를 동일한 날짜에 시작할 필요는 없지만 비교 시 각자의 관찰 기간은 같게 맞춰요.

## 8. 예산안

월 100만 원은 확정 예산이 아닌 현금 지출 상한 예시예요. 내부 제작 인건비는 별도이며, 부족하면 콘텐츠 수량을 줄여요. 외주·협업 비용은 견적에 따라 조절해요.

| 항목 | 월 상한 예시 | 사용 조건 |
|---|---:|---|
| 인터뷰·테스트 참여 보상 | 20만 원 | 예: 심층 인터뷰 10명 × 2만 원, 전체 체험자 지급은 아니에요 |
| 영상 편집·번역·언어 검수 | 25만 원 | 실제 화면 기반, 부족하면 원본 수량 축소 |
| 소규모 크리에이터 실험 | 20만 원 | 견적 안에서 가능한 1건부터 |
| 유료 광고 실험 | 15만 원 | 활성화·재방문 기준 확인 후 |
| 베타 AI 사용·운영 도구 | 10만 원 | 사용량을 계측하고 한도에 맞춰 모집 규모 조절 |
| 예비비 | 10만 원 | 품질·지원 문제 대응 |
| 합계 | 100만 원 | 미집행 항목을 억지로 소진하지 않아요 |

무료 또는 무제한 사용을 선약하지 않아요. 예산이 더 커져도 고객군·채널을 동시에 늘리기보다 검증된 소재의 반복 실험과 학습자 언어 검수에 먼저 배정해요.

## 9. 측정과 의사결정

핵심 지표는 **일주일에 3일 이상 유효 대화를 한 학습자 수**예요. 유효 대화는 학습자의 목표 언어 메시지 3개 이상이 각각 AI 응답을 받은 대화로 정의해요. 음성 홍보 캠페인은 음성으로 참여했는지도 별도 집계해요. 메시지 수는 회화 실력 향상의 직접 증거가 아니에요.

| 지표 | 정의 | 활용 |
|---|---|---|
| 소개 페이지 신청률 | 중복을 제외한 신청자 / 해당 페이지 고유 방문자 | 메시지·모집 조건 점검 |
| 활성화율 | 계정 생성 후 24시간 내 유효 대화와 피드백 확인을 마친 사람 / 신규 계정 생성자 | 첫 사용 경험 점검 |
| 7일 재대화율 | 활성화 후 6·7·8일차 중 다시 유효 대화를 한 사람 / 8일 관찰을 마친 활성 사용자 | 반복 사용 점검 |
| 주간 반복 사용자 | 한 주에 서로 다른 3일 이상 유효 대화를 한 사람 | 계속 쓸 가치 확인 |
| 유지 사용자 확보 비용 | 채널별 모집·소재·보상 현금 지출 / 해당 채널의 7일 재대화 사용자 | 초기 채널 비교 |

채널별 비용 외에 두 고객군의 공통 제작비·운영비와 투입 시간도 함께 기록해요. 분모가 0이면 비용을 0원으로 보고하지 않고 산출 불가로 표시해요. 유료 결제 고객 확보 비용(CAC)과 위의 유지 사용자 확보 비용은 구분해요.

**초기 운영 기준 제안:** 계정 생성자 20명 이상이 관찰된 언어별 그룹에서 활성화율 50%와 7일 재대화율 25%를 검토 기준으로 사용해요. 업계 평균이 아니며, 작은 표본의 결과에는 반드시 “10/20명”처럼 원자료를 붙여요. 기준 통과는 소액 후속 실험의 조건일 뿐, 시장 적합성이나 광고 수익성을 입증하지 않아요. 두 모집 차수에서 같은 방향인지 확인한 뒤 70:30 집중안을 적용해요.

- 클릭·신청은 있지만 대화 시작이 적으면, 설치·로그인·마이크 권한·첫 상황 선택을 관찰해요.
- 시작은 많지만 재대화가 적으면, 응답 대기·피드백 이해·다음에 할 말이 있는지 확인해요.
- 재대화는 좋지만 유입이 적으면, 같은 학습자에게 닿는 제작자·모임을 추가해요.
- 클릭률만 높고 실제 사용이 낮은 영상은 광고 확대 후보에서 제외해요.

추적은 언어·유입 채널·소재 ID·모집 차수·방문/신청/계정 생성/첫 대화/피드백 확인/재대화를 연결하는 최소 장부로 시작해요. 동의한 베타 참여자 기록과 앱 내 짧은 유입 경로 질문을 활용할 수 있어요. 설치 전 링크의 UTM이 자동으로 앱 계정까지 연결된다고 가정하지 않아요. 관찰하지 못한 피드백 열람은 추정값으로 채우지 않아요.

기존 코드에서 마케팅 분석 도구나 결제 이벤트가 충분히 구현됐다는 근거는 찾지 못했어요. 정식 확대 전에 위 이벤트를 계측하는 별도 구현이 필요해요. 유료 고객 확보 비용과 수익성은 실제 가격·결제 전환·반복 결제·고객별 AI 비용이 쌓인 뒤 평가해요.
