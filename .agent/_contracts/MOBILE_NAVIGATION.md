# 모바일 내비게이션 계약

> 상태: ACTIVE · 최종 갱신: 2026-10-09

- 하단 탭은 홈(`/home`)과 내 정보(`/profile`) 두 개예요. 두 탭은 전환 시 화면과 스크롤 위치를 유지하고, 같은 탭을 다시 누르면 맨 위로 이동해요.
- 홈 헤더는 왼쪽에 초록 가로형 Toma Talk 로고(`mobile/logo_img/KakaoTalk_Photo_2026-10-08-22-20-21 002.png`, 표시 영역 164 × 40pt, 기본 왼쪽 여백에서 8pt 이동), 오른쪽 끝에 현재 언어 쌍 배지를 표시해요. 로고는 탭 동작이 없고 내 정보 진입은 하단 탭을 사용해요.
- 홈의 주간 주제 앞 섹션 제목은 `오늘의 토마토`이며, 16px 버튼 서체와 좌우 8px 여백을 사용하고 가운데 정렬해요. 오른쪽 `전체 보기` 버튼은 표시하지 않아요.
- 전체 대화 목록(`/history`)은 기존 직접 진입 경로로 유지해요. 이 화면에서는 하단 탭을 숨기고 뒤로가기로 홈에 복귀해요.
- 전체 대화 목록에서 기존 대화를 열고 돌아오면 목록으로 복귀해요. 준비·대화 화면도 하단 탭을 숨겨요.
- 대화 화면에 직접 진입해 돌아갈 스택이 없으면 홈(`/home`)으로 이동해요.
- 홈 대화 카드는 왼쪽 제목과 오른쪽 `freechat`/`roleplaying` 유형 배지를 표시해요. 배지 문구는 한국어·영어 UI에서 같아요. 잠긴 대화는 카드 전체에 회색 오버레이와 중앙 자물쇠를 표시하고 별도 상태 텍스트는 두지 않아요. 스크린 리더에는 잠긴 상태를 알려줘요. 카드를 왼쪽으로 밀면 `삭제` 동작이 드러나고, 누르면 기존 삭제 확인 대화상자가 열려요. 열려 있는 카드를 누르면 닫히고, 닫힌 카드를 누르면 대화로 이동해요.
- 홈에서 맨 위를 아래로 당기면 권한을 먼저 갱신해 구독 변경에 따른 대화 잠금을 반영하고, 이어서 대화 목록과 홈 콘텐츠를 새로고침해요. 대화가 없는 상태에서도 당겨서 새로고침할 수 있어요.
- 홈 대화 목록은 활성 대화를 잠긴 대화보다 먼저 표시해요. 각 그룹 안에서는 서버가 반환한 최신 수정 순서를 유지하며 전체 대화 목록 API와 기록 화면의 순서는 바꾸지 않아요.
- 홈 진입에서는 대화 목록과 권한을 각각 조회하고 두 최신 응답이 모두 준비될 때까지 카드 영역에 로딩을 표시해요. 권한 조회 실패 시 잠금 없는 카드 대신 재시도 안내를 표시하고, 확인 전에는 새 대화 시작 버튼을 비활성화해요. 홈 당겨서 새로고침은 기존처럼 권한 조회 후 목록을 갱신해요.
- 홈 대화 목록은 정렬된 첫 5개만 기본 표시해요. 6개 이상이면 남은 개수를 알리는 `더 보기` 버튼으로 나머지를 펼치고 `접기`로 다시 5개만 보여줘요. 계정을 바꾸면 펼침 상태를 초기화해요. 펼침은 화면 표시 상태이며 기존 홈 API의 전체 페이지 조회 방식은 유지해요.
- 내 정보 화면에서 아래로 당기면 현재 계정의 프로필과 구독 플랜을 다시 조회해요. 화면이 짧아도 동작하며, 프로필 조회는 계정을 재초기화하지 않아요.
- API 계약과 대화 기록 조회·시작 방식은 변경하지 않아요.
