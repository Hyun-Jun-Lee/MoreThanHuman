# 모바일 내비게이션 계약

> 상태: ACTIVE · 최종 갱신: 2026-10-09

- 하단 탭은 홈(`/home`)과 내 정보(`/profile`) 두 개예요. 두 탭은 전환 시 화면과 스크롤 위치를 유지하고, 같은 탭을 다시 누르면 맨 위로 이동해요.
- 홈 헤더는 왼쪽에 초록 가로형 Toma Talk 로고(`mobile/logo_img/KakaoTalk_Photo_2026-10-08-22-20-21 002.png`, 표시 영역 164 × 40pt, 기본 왼쪽 여백에서 8pt 이동), 오른쪽 끝에 현재 언어 쌍 배지를 표시해요. 로고는 탭 동작이 없고 내 정보 진입은 하단 탭을 사용해요.
- 홈의 주간 주제 앞 섹션 제목은 `오늘의 토마토`이며, 16px 버튼 서체와 좌우 8px 여백을 사용하고 가운데 정렬해요. 오른쪽 `전체 보기` 버튼은 표시하지 않아요.
- 전체 대화 목록(`/history`)은 기존 직접 진입 경로로 유지해요. 이 화면에서는 하단 탭을 숨기고 뒤로가기로 홈에 복귀해요.
- 전체 대화 목록에서 기존 대화를 열고 돌아오면 목록으로 복귀해요. 준비·대화 화면도 하단 탭을 숨겨요.
- 대화 화면에 직접 진입해 돌아갈 스택이 없으면 홈(`/home`)으로 이동해요.
- 홈 최근 대화 카드는 왼쪽 제목과 오른쪽 `freechat`/`roleplaying` 유형 배지를 표시해요. 배지 문구는 한국어·영어 UI에서 같아요. 잠긴 대화에는 `읽기 전용` 상태를 추가해요. 카드를 왼쪽으로 밀면 `삭제` 동작이 드러나고, 누르면 기존 삭제 확인 대화상자가 열려요. 열려 있는 카드를 누르면 닫히고, 닫힌 카드를 누르면 대화로 이동해요.
- API 계약과 대화 기록 조회·시작 방식은 변경하지 않아요.
