# Language Snacks API Contract

> Status: ACTIVE · Version: 2.8 · Updated: 2026-09-20

외부 계약의 단일 기준은 [DSL Language Snack 모듈](../../docs/DSL.md#5-language-snack-모듈)이에요. CLI는 [README](../../README.md#스낵-콘텐츠-생성), 배포는 [운영 가이드](../../docs/OPERATIONS.md#언어-스낵-운영), 설정은 [환경변수](../../docs/ENVIRONMENT.md), 내부 상태·중복 검사는 [아키텍처](../architecture.md)를 참고해요.

## Scope

- content_language는 학습 대상 언어, explanation_language는 설명 언어예요. 현재 영어 학습은 한국어 설명, 한국어 학습은 영어 설명을 제공해요.
- JSONB payload는 regional_variant, usage_contrast, homonym이며 schema_version은 1이에요. identity와 knowledge_key는 표시 데이터와 분리하며 학습자 API에 노출하지 않아요.
- GET v2는 Bearer profile.target_language 기준 published 12개(최대 30개)를 반환해요. `order=latest`가 기본이고 `order=random`은 전체 발행 목록에서 중복 없이 무작위 추출해요.
- POST/PATCH v2는 서버 운영 키로 보호하며 일반 학습자 앱에는 생성 기능·키를 넣지 않아요.
- GET `/api/v2/language-snacks/basket-reset/`은 Bearer 사용자의 현재 학습 언어별 최신 `reset_id`를 반환해요. 기록이 없으면 null이에요. 같은 경로 POST는 운영 키로 보호하며 `{user_id, content_language}` 대상의 새 리셋 ID를 저장해요. 사용자·언어별 마지막 기록만 유지하며 일반 앱에는 운영 키를 넣지 않아요.
- 정규화 identity UNIQUE와 전체 이력 기반 LLM 중복 검사, 자동 품질 검증을 통과해야 발행해요. 의미 중복 방지에 통계적 오차가 남아요.
- 구 API는 GET 빈 목록 / POST 410을 반환해요. 마이그레이션 시 기존 스낵 데이터는 모두 삭제해요.

## Client

- 학습 언어 변경 시 즉시 재조회하고 언어별 캐시 키를 분리해요. 실패 시 해당 언어의 마지막 성공 목록만 사용해요.
- Home 재진입·앱 복귀 후 5분 이상 경과했다면 목록을 재조회하되 이미 정한 당일 묶음은 유지해요. 당일 콘텐츠 열람은 네트워크를 호출하지 않아요.
- 알려지지 않은 type/schema_version은 건너뛰고 손상된 기존 유형은 응답 실패로 취급해요.
- 오프라인에 이미 저장된 발행 취소 카드를 서버에서 즉시 삭제할 수는 없어요.

### 토마토 상호작용 v1 (2026-09-18 구현 결정)

- 디버그 빌드에서만 열람 수 옆에 테스트용 리셋 아이콘을 표시해요. 같은 기기·사용자·학습 언어의 당일 카드 순서와 서버 리셋 ID를 유지하며 소비만 0으로 저장하고 닫힌 바구니로 돌아가요. 모션·팝업 중에는 비활성화하고 release/profile에서는 버튼과 로컬 리셋 동작을 제공하지 않아요. 운영 POST·키·새 콘텐츠 조회는 사용하지 않아요.
- 바구니에서 토마토를 꺼내고 4입마다 하나를 완료해요. 총 3개, 12회 콘텐츠 팝업을 제공하며 자동 슬라이드는 제거해요.
- 4·8·12번째 팝업을 닫으면 남은 토마토 2·1·0개 바구니로 돌아가요. 다음 토마토는 바구니를 다시 눌러 꺼내며 이 터치는 콘텐츠를 소비하지 않아요. 재진입 시 완료 경계에서는 해당 바구니, 먹는 중에는 한입 진행을 복원해요.
- 꺼내기는 PNG 이동·확대·옅은 반동과 바구니 페이드로 400ms 동안 재생해요. 꺼내는 중에는 중복 입력을 막고 자정 갱신을 종료까지 미뤄요. 모션 감소 설정에서는 즉시 전환하며 화면 폐기 시 애니메이션을 취소해요. 별도 영상·라이브러리·에셋은 추가하지 않아요.
- 터치 영역의 기본 잉크 물결·눌림 배경은 표시하지 않고 토마토 자체의 애니메이션으로 피드백해요. 팝업 내부 페이지 번호는 없애고 Home의 일일 진행 표시는 유지해요.
- "오늘의 언어" 제목과 바구니·토마토 하단 점 표시는 제거해요. 이미지 단계·접근성 이름과 Home 일일 열람 수는 유지해요.
- 앱 시작·Home 진입·앱 복귀 시 서버 리셋 ID를 확인하고 저장된 ID와 다르면 당일 같은 카드 묶음의 소비 횟수를 0으로 돌려요. 리셋 ID도 함께 저장해 같은 요청을 반복 적용하지 않아요. 팝업·애니메이션 중에는 적용을 미루고, 오프라인·구 서버 404에는 기존 진행을 유지해요. 리셋은 푸시가 아니며 각 기기가 서버 조회에 성공한 시점에 반영돼요.
- 당일 최초 구성 시 `order=random`으로 받은 학습 언어별 목록을 사용해요. 12개 미만이면 목록의 각 항목을 한 번씩 본 뒤 반복 배치하며, 빈 목록과 캐시가 모두 없으면 영역을 숨겨요.
- 사용자 ID·학습 언어별로 기기의 로컬 날짜, 12개 본문 스냅샷·순서와 진행 횟수를 secure storage에 저장해요. 앱 재실행·화면 재진입·당일 목록 갱신에도 유지하고 기기 간 동기화는 하지 않아요.
- 세 토마토를 다 먹으면 12/12 소진 상태를 유지하고 추가 터치는 비활성화해요. 앱을 재실행해도 당일에는 다시 채우지 않아요. 기기 현지 시간 자정에 새 묶음을 구성하며, 앱이 백그라운드에 있었다면 복귀 시 날짜를 확인해요. 팝업·한입 애니메이션 중 자정이 지나면 닫힌 뒤에 갱신해요.
- 네트워크 실패에는 마지막 목록 캐시를 사용해요. 로컬 저장 실패는 현재 세션 사용을 막지 않지만 재실행 시 복원이 보장되지 않아요.
- `snack_content_tomato/` 원본 9장을 앱 assets로 복사해 사용해요. 바구니는 3·2·1·0개 네 단계, 토마토는 `last_tomato.png`까지 다섯 단계예요. 마지막 입의 팝업 중에는 꼭지 이미지를 유지하고 닫힌 뒤 바구니로 전환해요. 이미지 영역은 투명하게 해 Home 배경에 표시해요. 이미지 교체와 눌림·반동은 Flutter가 처리하고 모션 감소 설정에서는 생략해요.
- 검증: 랜덤 조회의 언어·발행 필터, 중복 없는 추출, 12회 소진·재시작·자정 리필, 중복 터치 차단, 날짜·사용자·언어 분리, 캐시·저장 실패, 작은 화면·큰 글자·접근성을 포함해요. 로컬 진행 저장은 기기 시계 변경·재설치에 대한 서버 이용 제한을 보장하지 않아요.
