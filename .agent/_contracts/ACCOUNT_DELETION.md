# 계정 삭제와 구독 권한 복원 — REVIEW

## 확정 정책

- 로그인한 사용자는 앱 안에서 계정 삭제를 요청할 수 있어요. 구독 취소는 삭제의 선행 조건이 아니에요.
- 요청을 수락하면 계정의 앱 접근을 즉시 막아요. 모든 필수 삭제가 끝나기 전에는 완료라고 표시하지 않아요.
- 프로필·대화·학습 기록·사용자별 스낵 진행·음성 캐시·기기 위젯 상태는 복원 없이 삭제해요.
- Apple의 자동 갱신 구독은 계정 삭제로 취소되지 않아요. 활성 구독에는 결제 지속 경고와 Apple 구독 관리 경로를 표시해요.
- 재가입한 사용자가 직접 구매 복원을 요청하면 현재 유효한 Apple 구독만 검증해 새 계정에 연결해요. 다른 활성 tomatalk 계정의 구매는 이전하지 않아요. 삭제된 학습 데이터는 복원하지 않아요.

## API 계약

- `DELETE /api/auth/me`: Supabase Bearer 인증, 본인 계정만 삭제해요. 요청을 영속화한 즉시 해당 계정의 보호 API 접근을 차단해요. 응답에는 서버가 생성한 영수증과 `apple_disconnect_required`가 있고, 필수 외부 작업이 완료되면 `completed`, 남으면 HTTP 202와 `processing`을 반환해요.
- `GET /api/auth/deletion-status/{receipt}`: 인증 없이 고엔트로피 영수증으로 `processing` 또는 `completed`만 반환해요. 이메일·계정 ID·삭제 자료는 반환하지 않아요.
- `POST /api/billing/apple/restore/`: 인증 계정이 StoreKit에서 받은 Apple 서명 거래를 제출해요. Apple 현재 상태를 다시 검증하고, 기존 활성 계정에 묶이지 않은 유효 구독만 새 계정으로 연결해요.

## 실패와 데이터 처리

- 삭제 요청·재시도 상태는 별도 최소 기록에 저장해요. 서버 작업은 중복 실행해도 안전해야 하고, 실패한 단계는 운영 작업으로 재시도해요.
- 기존 Supabase JWT는 사용자 삭제 후 만료 전까지 유효할 수 있으므로 모든 보호 API는 삭제 요청 기록을 확인해요. 이전 토큰으로 프로필을 다시 만들 수 없어야 해요.
- Apple 로그인 계정은 삭제 직전에 재인증해 토큰 폐기에 사용할 코드를 받아요. 설정 또는 외부 장애로 폐기할 수 없으면 Apple의 수동 연결 해제 경로를 안내하고, 계정 데이터 삭제는 계속 진행해요.
- 구매 거래의 최소 메타데이터만 복원·중복 연결 방지에 필요한 기간 보관하고 이메일·닉네임·대화와 분리해요. 법정 보존 범위는 출시 전 개인정보처리방침과 대조해요.
