# Weekly Conversation Topics — ACTIVE

주간 추천은 로그인한 사용자의 학습 언어쌍에 공통으로 발행돼요. 운영자가 서버 CLI를 직접 실행해 생성하며 예약 worker는 이 계약의 범위 밖이에요.

## Publication

- 지원 언어쌍은 `ko→en`, `en→ko`예요. 문구는 모국어로, AI의 첫 질문은 학습 언어로 제공해요.
- 주간 슬롯은 월요일 05:00 Asia/Seoul부터 시작해요. 언어쌍·슬롯별 발행 묶음은 하나예요.
- 생성 결과 8개를 목표로 하고 최소 6개가 서버 검사를 통과해야 한 묶음으로 발행해요. 실패하면 마지막 발행 묶음을 유지해요.
- 생성기는 각 모국어 주제와 학습 언어의 짧은 첫 질문을 함께 만들고 둘 다 검증해요. 첫 질문이 없는 기존 주제는 시작할 수 없어요.
- 기본 CLI 재실행은 기존 묶음을 유지해요. 명시적 재발행은 검증이 모두 끝난 뒤 같은 주차의 활성 주제 ID를 유지하며 문구·첫 질문을 한 트랜잭션에서 교체해요. 기존 활성 주제보다 새 주제가 많으면 새 ID를 추가하고, 보관된 주제는 그대로 보관해요. 새 후보가 기존 활성 개수보다 적으면 재발행하지 않아요.
- 재발행은 12쌍의 후보를 요청해 형식·중복·안전성 검사를 통과한 최대 8쌍을 사용해요. 검증 실패는 기존 발행을 보존하고 CLI에 실패 단계와 검증 개수만 표시해요. 원문·비밀 설정·DB 오류 내용은 출력하지 않아요.
- 운영자가 보관한 주제는 목록과 시작 대상에서 제외해요. 이전 주차에 발행된 나머지 주제는 시작할 수 있어요.

## API

- `GET /api/conversation-topics/weekly/`는 인증된 profile의 언어쌍에서 최신 발행 묶음을 반환해요. 성공 `data`는 `{week_start, topics: [{id, text}]}`예요. 목록이 없으면 `week_start: null`, `topics: []`예요.
- `POST /api/conversations/start/free-chat/suggested/`는 `{topic_id, start_request_id, include_audio_response}`를 받아요. 성공 `data`는 `{conversation_id, assistant_message_id, conversation_type, language, response, audio?, audio_error?}`예요.
- 시작 시 profile 언어쌍, 발행 및 보관 상태, 첫 질문 존재 여부, 대화 슬롯을 검사해요. 생성된 대화는 `FREE_CHAT`이고 첫 메시지는 발행 시 저장된 AI 질문 하나예요. 사용자 발화 수는 0이에요.
- `start_request_id`는 클라이언트가 탭마다 만든 UUID예요. 같은 사용자와 요청 ID의 성공한 요청은 같은 대화·첫 메시지를 반환해요. 처리 중 요청의 중복 호출은 `START_IN_PROGRESS`예요.
- 탭 시 웹 검색·사실 확인·Topic Prep 검사는 실행하지 않아요. 발행 전에 형식·중복·안전성 검사를 실행해요.

## Mobile

- 발행된 주제가 있으면 홈의 대화 목록 상태와 저장된 대화 수에 관계없이 추천 영역을 표시해요. 대화가 0개일 때는 기존 빈 상태 안내도 함께 보여줘요.
- 홈은 ‘최근 대화’ 제목, 주간 주제 카드, 최근 대화 카드 순서로 배치하고, 빈 상태의 ‘대화를 시작하세요’ 안내는 작은 제목 크기로 표시해요.
- 주제는 제목·공통 배경 박스 없이 밝은 회색 카드와 검정 글자로 표시하고, 각 카드 상단 테두리 중앙에 초록 토마토 꼭지 이미지를 걸쳐요. 탭한 주제의 모든 반복 카드는 즉시 빨간색으로 바뀌고, 확인 팝업이 열린 동안 이동을 멈춰요. 취소하거나 시작에 실패하면 회색으로 돌아가요. 손가락으로 좌우로 밀면 그 거리만큼 이동하고 손을 떼면 현재 위치에서 자동 흐름을 이어가요. 터치 중 이동을 멈추고 동작 줄이기 및 접근성 탐색에서는 정적 선택 목록을 보여줘요.
- 카드를 탭하면 선택한 주제를 포함한 시작 확인 팝업을 화면 중심보다 위에 보여줘요. 선택된 카드의 색 변화가 팝업 아래에서도 보이도록 배치해요. 취소 시 API를 호출하지 않고, 시작 확인 후 ‘대화 시작을 준비하고 있어요’ 로딩 상태를 카드 자리에서 보여주며 중복 시작을 막아요.
- 추천 조회가 실패하면 같은 계정·언어쌍의 마지막 성공 목록을 사용해요. 캐시도 없으면 추천 영역을 숨겨요.
